# Contributing

AI-DSL keeps grammar metadata, parser behavior, examples, and generated documentation synchronized.

## Checks

```bash
python -m unittest discover -s tests
python -m src.docgen --check
```

## Pull requests

- Discuss grammar changes before implementation.
- Add valid and invalid examples for new syntax.
- Regenerate documentation with `python -m src.docgen`.
- Keep syntax diagnostics precise and position-aware.
- Do not add generated bytecode, local environments, or third-party course materials.

No repository-wide license is currently declared because the checked-in course brief requires a separate rights review. Contributions must be your own work and do not change that status.
